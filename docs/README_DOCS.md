# OneDayCompany Documentation

This folder is the shared project memory.

## Read first

For a new development session, read in this order:

1. `PROJECT_BRIEF.md`
2. `CHAT_HANDOFF.md`
3. `DECISIONS.md`
4. the relevant section of `ARCHITECTURE.md`
5. the current milestone in `ROADMAP.md`

## Files

### `PROJECT_BRIEF.md`

Stable, compact overview of the project, current implementation and next milestone.

### `VISION.md`

Mission, product philosophy and long-term direction.

### `ARCHITECTURE.md`

Current and near-term technical structure.

### `DECISIONS.md`

Durable product and architecture decisions.

### `ROADMAP.md`

Completed, current and future milestones.

### `CHAT_HANDOFF.md`

Current operational state. Update after every substantial session.

### `AI_COLLABORATION.md`

Procedure for working efficiently across separate AI chats.

### `SESSION_TEMPLATE.md`

Reusable template for planning and closing a development session.

### `CHANGELOG.md`

Notable changes to the project.

## Update frequency

| File | Update when |
|---|---|
| `PROJECT_BRIEF.md` | The overall project status changes materially |
| `VISION.md` | Rarely; only when the product direction changes |
| `ARCHITECTURE.md` | The technical structure changes |
| `DECISIONS.md` | A durable decision is accepted or superseded |
| `ROADMAP.md` | A milestone or priority changes |
| `CHAT_HANDOFF.md` | At the end of every substantial session |
| `CHANGELOG.md` | A notable feature or change is completed |
