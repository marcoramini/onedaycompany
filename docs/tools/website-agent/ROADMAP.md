# Website Agent — Roadmap

**Current status:** Paused until the initial Visual Asset Agent contracts and
asset lifecycle are accepted.

## Phase 0 — Product and contract design

- [x] Accept the Website Agent direction.
- [x] Reject a visual page builder for the first release.
- [x] Establish structured proposals and explicit acceptance.
- [x] Separate logo identity from promotional imagery.
- [ ] Choose the first two template archetypes.
- [ ] Define section and theme catalogs.
- [ ] Define site-document, revision and agent-operation Zod contracts.
- [ ] Adopt Visual Asset Agent brief and result contracts.

## Phase 1 — Deterministic renderer

- [ ] Implement the first two application-controlled templates.
- [ ] Render a fixture site document responsively.
- [ ] Add site-document validation and schema versioning.
- [ ] Add a local preview route.
- [ ] Verify accessibility and responsive behavior.

## Phase 2 — Initial generation

- [ ] Assemble company context server-side.
- [ ] Select a template and generate structured content.
- [ ] Generate SEO metadata and one primary CTA.
- [ ] Persist a draft without publishing it.
- [ ] Provide deterministic fallback content.

## Phase 3 — Visual Asset Agent integration

- [ ] Build structured briefs for required website assets.
- [ ] Request and select variants from the Visual Asset Agent.
- [ ] Attach durable assets with suitable aspect ratios and alt text.
- [ ] Reuse the approved company logo and visual direction.

## Phase 4 — Conversational changes

- [ ] Add the focused Website Agent interface.
- [ ] Generate typed change proposals without direct writes.
- [ ] Validate operations and identify affected sections and assets.
- [ ] Render a preview revision and change summary.
- [ ] Apply only after explicit acceptance.
- [ ] Preserve revision history.

## Phase 5 — Publication

- [ ] Create immutable published snapshots.
- [ ] Resolve a globally unique public slug.
- [ ] Serve the published site from the shared renderer.
- [ ] Support rollback to an earlier published snapshot.
- [ ] Add cache invalidation and publication observability.

## Phase 6 — Addressing and expansion

- [ ] Add wildcard `*.onedaycompany.com` resolution.
- [ ] Add verified custom domains and managed TLS.
- [ ] Add further template archetypes based on real usage.
- [ ] Enable multiple pages without changing the agent safety boundary.
- [ ] Evaluate a second image provider using measured quality and cost.
