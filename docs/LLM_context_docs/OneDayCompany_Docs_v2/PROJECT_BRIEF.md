# PROJECT_BRIEF v2

## Mission
OneDayCompany transforms existing skills into real businesses.

## Product Vision
OneDayCompany is a Company Workspace. The guided flow creates the initial company; afterwards the Workspace becomes the permanent operating environment.

## Principles
- One screen, one objective
- Company Workspace, not AI chat
- Validation through action
- Persistent company assets
- Practical progress over planning

## User journey
Landing → /start → Authentication → Company Workspace
