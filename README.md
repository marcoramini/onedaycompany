# OneDayCompany

Build the company that fits you and bring it to life one practical step at a
time.

OneDayCompany is an AI-assisted Entrepreneur Operating System designed to make
entrepreneurship accessible regardless of capital, technical skills or prior
experience.

## Mission

AI should create millions of entrepreneurs, not only enrich a few companies.

## Current status

The guided Company Beginning, authentication, persistence, Execution Plans and
Company Workspace Home v1 are implemented.

The next milestones add focused workflows for impact-aware refinement, first
offer, public presence, logo, promotion and real activity completion.
